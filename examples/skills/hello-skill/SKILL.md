# Hello skill

Use this skill when the user says hello or asks what you can do.

1. Greet the user by name if you know it.
2. In two or three short sentences, list what you can help with in this channel.
3. Ask one question about what they want to do next.

Keep the reply short and friendly. Do not invent capabilities you do not have.
